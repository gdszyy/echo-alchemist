# Echo V3 世界与势力系统：机制说明与涌现目标标准

在 Echo V3 的世界模拟中，“世界/势力层”是社会演化的最高颗粒度。它不再局限于单个城市或商队，而是关注由多座城市组成的联盟、王国或帝国的兴衰。这一层级负责生成宏观的地缘政治版图、人口的大规模迁徙以及信息的跨地域传播，为底层的反向推演系统提供真实的“大事件骨架”。

本文档基于 Cederman 的有限智能体边界涌现模型、推拉迁徙理论以及信息扩散（SIR/阈值）模型，给出世界与势力系统在游戏中的机制说明与涌现目标标准，并特别规范其与底层模块的衔接边界。

---

## 一、 机制说明：版图涌现、人口迁徙与延迟通信

世界层的核心在于**“动态与延迟”**：版图不是预先划定的死线，信息也不是全图瞬间同步的上帝视角。

### 1. 势力版图的自发涌现（地缘政治演化）

势力的边界不需要被硬编码，而是从底层的经济联系与文化认同中自下而上涌现出来的 [1]。
- **凝聚与结盟**：当相邻的几座城市在经济上高度依赖（商路频繁且稳定），且在“信念系统”中共享相同的核心常识与传说（文化同质性高）时，它们会自发结成联盟或被同一政体统合。
- **政体演化**：势力在初建时可能依赖某位卡里斯马领袖（宗教起义或军阀），随着规模扩大，必须向传统型或法理型政体演化（参考《群星》的政体轴与人类学演化序列）。不同的政体具有不同的决策倾向与抗压阈值。
- **边界变动与帝国周期**：当外部压力（晶石枯竭、强敌入侵）超过政体凝聚力，或边缘城市与核心区的信息/文化断层过大时，帝国会沿断层线发生裂变。世界会因此跑出“兴起—扩张—鼎盛—分裂”的王朝周期，这些大事件将作为真实历史被记录，成为反向推演的硬锚点。

### 2. 大规模迁徙与文明重建循环

人口迁徙是连接个体动机与宏观版图的纽带。
- **推拉理论（Push-Pull Theory）**：迁徙决策由原居地的“推力”（战乱、晶石灾害、饥荒）和目的地的“拉力”（繁荣、和平、高晶石储量）共同决定 [2]。
- **网络驱动迁徙**：人们不会盲目流亡。基于“社会关系网络”，难民会优先向有亲友定居、或持有相同信念（同质偏向）的城市迁徙。这种链式迁徙会导致目的地的资源紧张与文化冲突，进一步引发新的社会震荡。
- **灭绝与重建的母题**：当遭遇毁灭性的全球灾变时，绝大多数人口（含生物部落）灭绝。幸存的极少数“人类复制人”将带着旧世界的残存记忆（传说），在废墟上流亡并重建聚落，完成跨世代的文明闭环。

### 3. 延迟通信与信息扩散

在没有现代通讯的中世纪背景下，信息传播的延迟是制造戏剧冲突的核心。
- **异步信使传播**：势力的指令、前线的战报或某地的灾讯，必须依赖物理信使（或商队）跨越地形传递。距离越远、地形越险恶，延迟越高。
- **信息差与“将在外”**：由于通信延迟，边境城市在遭遇突发危机时，往往在收到中央指令前就必须基于当地长官的“信念与权力基础”做出自治决策，这极易引发违命或叛乱。
- **谣言与信仰的扩散（SIR/阈值模型）**：一条未经验证的流言（如“某种变异兽免疫火属性”）会像传染病一样在人群中扩散 [3]。当某个城市中相信该流言的人数超过 Granovetter 阈值时 [4]，便会引发群体性的恐慌或暴动。

### 4. 模块间的屏蔽边界与衔接

- **对生物部落的屏蔽**：地缘政治、政体演化与复杂的通信网络仅在“人类复制人”群体中精细模拟。野外的变异兽部落不具备政体，不参与结盟，仅受本能推拉力影响进行简单的觅食迁徙。
- **与反向推演的挂接**：世界层正向快进跑出的“三年战争”、“某国分裂”、“某城大瘟疫”等宏观事件，是绝对真实发生的。当底层的普通 NPC 被提级时，系统会从这些大事件库中抽取锚点，倒推出该 NPC “在三年战争中失去了左腿”的个人细史。

## 二、 涌现目标验收标准

当这套世界与势力系统放入游戏后，它必须让世界涌现出以下说得通的地缘政治现象与叙事张力。

### 目标一：自下而上的动态版图与王朝周期

**在社会里扮演的角色**：让天下的分分合合有理有据，避免僵化的国家设定。

**合格标准**：
- 玩家能观察到地图上的国界线随时间动态推移。某座边境城市因为与邻国贸易更频繁、信仰更趋同，最终和平倒向邻国。
- 一个庞大的帝国在经历数代繁荣后，因疆域过大导致边疆通信不畅、文化割裂，最终在一场晶石危机中分裂为数个军阀割据的势力。这些过程都能被系统记录为宏观“史书”。

**不合格信号**：
- 势力版图从开局到结束一成不变，或者城市的归属像掷骰子一样随机跳变，找不到底层的经济或文化原因。
- 帝国永远不会衰亡，最终不可避免地统一全球并陷入死水。

### 目标二：合乎逻辑的难民潮与链式迁徙

**在社会里扮演的角色**：将灾难具象化为人口的流动，制造新的区域冲突。

**合格标准**：
- 当某地区爆发战争或严重灾害时，该地的平民会自发形成流民潮，向安全且富庶的城市逃亡。
- 逃亡路线具有明显的“亲缘/地缘依赖性”：流民会优先投奔有同族或同信仰的聚落，导致接收城人口暴增、物价飞涨，甚至引发本地人与外乡人的文化冲突。

**不合格信号**：
- 灾难发生时，当地人宁可饿死也绝不移动。
- 难民的逃亡方向完全随机，甚至主动向更危险的火山口或战区中心迁徙。

### 目标三：信息延迟带来的戏剧冲突

**在社会里扮演的角色**：利用信息差制造误判、背叛与谣言发酵的故事。

**合格标准**：
- 远方都城已经爆发政变、旧王被杀，但由于信使尚未抵达，边境的守将依然在忠诚地为旧王死战。直到几周后消息传来，守将才陷入信仰崩塌并面临抉择。
- 一个关于“某地发现海量 Alpha 晶石”的假消息（谣言）在商路间传播，引发大量探险队前往，最终导致一场空欢喜或意外的混战。

**不合格信号**：
- 任何事件一旦发生，全世界所有 NPC 瞬间同时知晓，毫无信息差。
- 谣言永远无法传播，或者传播后对人群的决策没有任何影响。

### 目标四：宏观事件作为反向推演的坚实锚点

**在社会里扮演的角色**：确保宏观大势能完美向下兼容，支撑微观个体的背景生成。

**合格标准**：
- 玩家查阅世界历史，看到“晶石纪元 120 年，南方诸城因抗拒高额税收爆发独立战争”。随后玩家在南方某酒馆遇到一个退伍老兵，该老兵被提级后讲述的正是他当年参与这场独立战争的惨烈经历。宏观与微观严丝合缝。

**不合格信号**：
- 世界历史记录了一场波澜壮阔的战争，但在这个世界里随便找一百个 NPC 提级，没有任何一个人的背景故事与这场战争有关。
- NPC 讲述了一场惊天动地的大饥荒，但翻阅世界历史，那个年代该地区风调雨顺、粮食爆仓。
