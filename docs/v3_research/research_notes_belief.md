# 常识/信念系统调研笔记（服务于个体 AI 决策的"常识"输入）

> 目标：回答用户四问——常识如何自发产生？如何传播/形成共识（含沟通中互相印证强化）？传说是否是一种常识？偏见是否是一种"错误的常识"？

## 1. 常识如何"自发产生"——文化演化 / 双重继承理论（Boyd & Richerson, Henrich）

- **文化 = "存储在个体大脑中、能影响行为的、通过社会学习获得的信息"**。它不是世界硬规则，而是个体层面的动态属性，连接"个体过程"与"群体结果"。这正好对应：常识应当存在于**每个角色自己脑子里**，而非全局真值表。
- **常识的来源 = 社会学习（social learning）**：① 直接观察/模仿他人行为；② 被他人教导；③ 个体自身试错的经验（个人学习）。
- **常识不是中立复制，而是带"传播偏向（transmission bias）"地获得**——这几条偏向直接回答了"常识为何从亲近的人/小团体/城市习得"：
  - **Success bias（成功偏向）**：模仿"过得更好"的人的信念/做法。
  - **Prestige/Status bias（威望偏向）**：模仿高地位者（首领、长者、祭司）。→ 对应"传说/权威之口"传播。
  - **Homophily bias（同质偏向）**：模仿与自己最像的人。→ 对应"亲近的人/同族"。
  - **Conformist bias（从众偏向）**：不成比例地采纳"更多人在做/在信"的那条。→ 这正是**共识形成与"沟通中互相印证"的核心机制**：一条信念被越多人持有/复述，越容易被采纳并被赋予更高优先级。
- **演化结构**：不同"文化变体（cultural variant）"有不同的存活/复制率，于是常识池像基因池一样被选择——有的常识扩散壮大、有的消亡。→ 常识系统应当让"信念变体"在人群中竞争、扩散、淘汰。

## 2. 常识如何"传播 / 形成共识"——信念扩散 + 社会认识论

- **传播载体 = 关系网络（已在领域二/四调研）**：常识顺着亲近的人→小团体→城市→势力逐跳流动，受地理与社交"桥"节点约束（SIR/级联/阈值模型）。
- **共识 = 反复印证累积的置信度**：
  - 一条信念每被一个（尤其是亲近的、可信的、高威望的）人**独立印证一次**，其在持有者心中的**可信度（confidence）与优先级（priority）** 上升（贝叶斯式累加 + 从众偏向）。
  - **社会认识论（Social Epistemology）关键区分**："基于知识的共识（knowledge-based consensus）" vs "仅仅是趋同的一致（mere agreement）"。前者各人有独立证据支撑，后者只是互相抄。→ 在游戏里二者都该存在：真·共识（多人各自验证为真）与伪·共识（互相复述形成的回音壁），后者正是谣言/偏见的温床。
  - **独立性陷阱**：若 A 信 X 只因听 B 说，B 信 X 只因听 A 说，则"两人都信"并不增加 X 为真的概率——这是回音室/偏见自我强化的机制根源，系统应能区分"独立来源数"与"复述次数"。
- **结论**：共识不是"全员变量一致"，而是"一条信念在足够多、足够可信、足够独立的来源处被印证，从而在群体中达到高持有率与高优先级"。

## 3. 传说是不是一种常识？——是，且是"高威望、跨代、抗证伪"的特殊常识

- **传说/谣言传播理论（Modern Legend and Rumor Theory）**：传说与谣言是**集体传播**（非单线传递），人们在转述中**增删改造**，使其越来越契合群体的恐惧/愿望——即传说在传播中被"打磨"得更易传播（贴合群体情绪）。
- **传说 = 常识的一个子类**，但有几个特征使其特殊：
  - **来源是"威望/权威/祖先"**（prestige bias 拉满）：由祭司、长者、史诗传唱，天然高可信度、高优先级。
  - **跨代传承**：不随单个个体死亡而消失，沉淀进"城市/势力/文化"层的集体常识。
  - **抗证伪**：往往指向无法被日常经验直接检验的对象（神灵、远古大战、禁忌之地），因此难以被个人经验推翻——可信度只增不减。
  - 在本项目里：传说可作为**文明重建后跨世代承接故事的载体**（旧文明的真实事件，在新文明里退化为半真半假的传说），呼应"灭绝-重生"母题与"反向圆故事"。

## 4. 偏见是不是"错误的常识"？——是，是"针对群体的、被情绪强化的、抗修正的错误常识"

- **GBN-Dialogue 模型（Group membership, Belief, Novelty）**：负面谣言/偏见在**对立群体**间传播时，受三因素放大：① 目标是否为**外群体（outgroup）**；② 是否契合传播者**已有信念**；③ 新奇性。→ 偏见 = 专门针对"外群体"的、契合既有信念的负面常识，传得特别快。
- **刻板印象/偏见的形成机制**（社会心理学）：
  - **错误关联（illusory correlation）**：把少数群体与少数负面事件错误关联。
  - **确认偏误（confirmation bias）**：只采信印证既有偏见的证据，忽略反例——使偏见**抗修正**（与"知识型常识"可被证据更新相反）。
  - **群际接触假说（contact hypothesis）**：与外群体的正向接触可削弱偏见——给出了"偏见可被消解"的机制，对应故事里的和解弧线。
- **偏见在系统中的定位**：它与"常识"用**同一套数据结构和传播机制**，区别仅在于：① 内容指向某个群体/标签；② 与事实不符（或过度泛化）；③ 因情绪（恐惧/仇恨）与确认偏误而获得**异常高的优先级和异常强的抗证伪性**。→ 不需要单独造系统，偏见是常识系统的一种"病态参数配置"。

## 5. 对 AI 决策输入的直接启示（待写入机制文档）

- 每个角色带一个**个人信念集（belief set）**：每条信念 = {内容, 可信度, 优先级, 来源集, 情绪色彩, 最近印证时间}。
- 角色做决策（调用 AI API）时，输入除客观处境外，还要**注入该角色当前 belief set 中与情境相关、且优先级最高的若干条**作为"它所相信的常识/世界观"——于是不同角色基于不同（甚至错误的）常识，对同一情境做出不同决策。
- 常识的产生：个人经验直接写入；社会学习按四种偏向从他人 belief set 复制（带失真）。
- 共识/印证：收到与已有信念一致的信息→可信度/优先级升；独立来源数与复述次数分开计。
- 传说：高威望来源注入、跨代不衰减、抗证伪的特殊信念。
- 偏见：指向群体标签、受确认偏误锁定、可被正向接触削弱的错误信念。
