# 社会分工与阶层生成调研笔记

> 本文件沉淀 Echo V3 “聚落出现后如何自然产生社会分工、职业、地位与阶级”的原始调研与抽象框架草案。它不直接规定实现方案或验收标准，而是为后续设计文档提供理论材料。

## 0. 游戏用最小模型：需求-岗位-增幅器分工

上一层理论可以进一步压缩为一个更适合游戏近似计算的核心判断：

> **社会分工 = 潜在需求被某些人捕捉，并在足够市场/用户支撑下稳定成岗位。  
> 岗位发展 = 岗位为了提高能力、效果和产出，持续需求建筑、设施和工具。  
> 社会地位/阶级 = 谁能稳定控制最关键、最可垄断的岗位，或控制岗位所依赖的关键设施/工具。**

也就是说，系统不需要先模拟完整历史，也不需要维护庞大的职业表。只要给每个聚落计算“哪些潜在需求变成了有效需求、谁有能力承接、承接后产生什么效果”，就能近似得到它的分工结构和上层人物。

这里要区分三层：

- **潜在需求**：客观上有问题或机会存在，例如矿区危险、粮食腐坏、商路不稳定、庇护炉需要维护。
- **有效需求**：有人愿意为解决它付出资源、服从、声望、人情或制度性供养。没有用户/市场/再分配来源，潜在需求不会稳定变成岗位。
- **岗位**：某个人或小团体发现有效需求，并以兼职、季节性或专职方式持续提供对应产出。
- **岗位增幅器**：建筑、设施、工具、牲畜/载具、武器、记录系统、炼金炉、庇护装置等，会提高岗位的能力上限、效果、产出或稳定性。

### 0.1 需求来源：个人市场与聚落综合需求

岗位不是直接从“有问题”里长出来，而是从“有人把问题表达为可交换、可征召或可供养的需求”里长出来。Echo 至少需要区分两类需求来源：

| 需求来源 | 形成方式 | 典型岗位 |
|----------|----------|----------|
| **个人/小团体需求** | 某些人发现自己愿意为产出付出 Beta 晶石、物资、人情、庇护或承诺；供给者多次接单后，形成“稳定生意”的常识 | 打铁、草药、护送、搬运、修屋、代购 |
| **聚落综合需求** | 聚落领袖、议事会、祭司、矿主或公共再分配系统，从整个聚落的生存和安全角度聚合需求，用税、贡、库存、征召或声望来支付 | 粮仓管理、巡逻队、清剿怪物、守桥、修渠、庇护炉维护 |

第一类更像市场自发岗位：一个人发现潜在需求，先与少数需求方达成交易；如果交易反复成功，需求方、供给方和旁观者都会逐渐形成一种常识：“这是一门稳定生意”。一旦这种常识传播开，岗位就不再只是某次交易，而会变成可被模仿、可被雇佣、可被传承的社会角色。

第二类更像公共/集体岗位：需求可能来自很多人的生存和安全，但单个个人未必愿意或有能力单独支付。例如清扫怪物、驱赶匪徒、维护水渠、储备粮食、守卫渡口。这类需求常有“所有人都受益、但没人单独愿意付全款”的问题，因此需要聚落层的权力或再分配机制把潜在需求转成有效需求。

### 0.2 聚落的综合需求层级

可以把聚落也看成一个有需求层级的主体，但它不是一个真实个人，而是由人口、库存、风险、设施和权力结构聚合出来的“集体需求面板”：

| 层级 | 聚落问题 | 可能形成的需求 |
|------|----------|----------------|
| **生存** | 食物、水、住所、燃料、Beta 晶石是否够用 | 农耕、采集、采矿、储粮、取水、基础维修 |
| **安全** | 怪物、匪徒、灾害、污染、火灾、商路风险 | 巡逻、守卫、清剿、城防、庇护炉维护、灾害预警 |
| **稳定** | 库存、价格、疾病、争端、劳动力是否失控 | 粮仓管理、医者、调停者、书记、税/贡收取 |
| **发展** | 能否提高承载、产出、交通和专业化 | 修渠、道路、工坊、工具制造、学徒训练、商队 |
| **意义/合法性** | 牺牲、分配、禁忌、共同记忆是否被解释 | 祭仪、传说讲述、纪念、教化、领袖合法化 |

个人需求和聚落需求会互相转化：很多人都想要安全，但没人能单独购买安全时，领袖可能把它聚合成巡逻队；巡逻队成功后，安全提高又扩大市场范围，让护送、商贸、修路等岗位更容易稳定。

### 0.3 五个输入

| 输入 | 含义 | 游戏里近似来源 |
|------|------|----------------|
| **剩余 S** | 除了维持基本生存，还能养活多少非基础劳动者 | 食物、Beta 晶石、庇护稳定度、单格承载余量 |
| **有效需求 D** | 谁需要这个产出，是否愿意付出代价 | 人口需求、商路订单、首领征召、互惠义务、庇护/安全需求 |
| **人员能力 A** | 当前有多少人能承接，能力是否达标 | 个体技能、经验、装备、健康、关系网络 |
| **门槛 T** | 该任务是否需要长期学习、稀有工具或组织能力 | 文化程度、炼金复杂度、武器复杂度、记录能力 |
| **垄断性 M** | 该任务或资源能否被少数人控制 | 矿脉集中度、武器稀缺度、路口/渡口、秘传知识、粮仓 |

### 0.4 五个职能槽

为了游戏可用，职业先不要细分为几十类，而是归入五个槽：

| 职能槽 | 解决的瓶颈 | 常见职业外观 |
|--------|------------|--------------|
| **供给** | 食物、水、矿、基础材料从哪里来 | 农人、采集者、矿工、猎人 |
| **转化** | 资源如何变成工具、建筑、药品、炼金武装 | 工匠、炼金师、建筑者、医者 |
| **防护** | 如何抵抗野兽、灾害、掠夺和战争 | 守卫、猎兽人、雇佣兵、城防维护者 |
| **流通** | 物资、信息和人如何跨距离移动 | 商人、驮队、信使、掮客 |
| **统合** | 谁来分配、裁决、记账、解释共同意义 | 首领、祭司、书记、议事会、粮仓管理员 |

一个具体职业可以占多个槽，但系统层只需先算槽。例如“炼金师”通常是转化 + 防护 + 知识地位；“商队首领”是流通 + 防护 + 统合。

### 0.5 直接近似规则

对每个职能槽计算一个“岗位机会”：

> **岗位机会 = 有效需求 D × 门槛 T × 可承接人数缺口 G**

- `D` 高：有足够用户、订单、再分配来源或社会义务支撑这个岗位。
- `T` 高：不是人人都能顺手做，必须有人专门学、专门管或专门持有工具。
- `G` 高：当前具备能力 `A` 的人不够，或现有人手效果差、成本高、风险大。

然后用剩余 `S` 从高到低支撑岗位机会：

- `S` 很低：岗位只能以临时/兼职出现，大多数人仍是泛用劳动者。
- `S` 中等：高需求岗位稳定兼职或季节性专职，例如矿工 + 守卫 + 工匠。
- `S` 较高：多个岗位可全职化，并开始有管理、记录、祭仪或信用中介。

岗位形态可按支撑强度分级：

| 形态 | 条件 | 例子 |
|------|------|------|
| **偶发任务** | 有需求但不稳定，靠临时互助或首领指派 | 临时修桥、灾后救援 |
| **兼职岗位** | 需求周期性出现，但不足以养活全职者 | 农闲打铁、兼职草药师 |
| **季节/事件专职** | 某季节或危机期需求集中 | 贸易季护卫、灾害季清理队 |
| **全职岗位** | 有稳定用户和剩余供养 | 专职矿工、炼金师、商队信使 |
| **制度岗位** | 岗位被组织、传统或规则固定 | 书记官、守备队、祭司团、行会 |

岗位从交易到常识可简化为：

> **岗位常识强度 = 成功交易次数 × 产出可见度 × 口碑传播范围 − 失败/欺诈记忆**

当岗位常识强度足够高时，系统可以把它视为“已被社会承认的稳定生意”：更多人会尝试学习它，需求方会主动寻找它，领袖或市场也更容易为它提供增幅器。

### 0.6 岗位匹配：能力与产出

每个岗位都必须对应“能力要求”和“产出/效果”，否则只是标签。

> **岗位成立 = 有效需求存在 + 有人具备最低能力 + 产出能被用户感知**

| 职能槽 | 能力要求 | 产出/效果 |
|--------|----------|-----------|
| 供给 | 体力、地形经验、工具使用、资源知识 | 食物、矿石、水、基础材料、库存稳定 |
| 转化 | 工艺技能、炼金知识、工具/炉具、学徒经验 | 工具、建筑、药品、武装、庇护设施维护 |
| 防护 | 武力、警戒、战术、装备、风险判断 | 降低伤亡、减少掠夺、保护商路/矿区 |
| 流通 | 路径知识、信用、谈判、算账、载具/驮兽 | 物资抵达、信息流动、价差套利、订单连接 |
| 统合 | 声望、记录、裁决、仪式、分配能力 | 资源分配、冲突调停、合法性、共同目标 |

人员会从既有身份出发捕捉岗位机会：农人可能农闲兼职护卫，矿工可能转成矿头，识字者可能成为账房，猎兽人可能被首领雇佣为守备队。岗位是否升级，取决于它的有效需求是否持续增长，以及承接者的产出是否被用户认可。

### 0.7 岗位增幅器：建筑、设施、工具

岗位一旦稳定，就会产生二级需求：为了更高产出、更低风险、更强可信度，它会需要建筑、设施和工具。这些东西可称为“岗位增幅器”。

> **岗位产出 = 人员能力 A × 增幅器 K × 资源输入 × 环境适配 − 风险/损耗**

| 职能槽 | 常见增幅器 | 产生的新需求 |
|--------|------------|--------------|
| 供给 | 农田、水渠、矿井、仓库、采矿工具 | 修建、维护、工具制造、运输、守卫 |
| 转化 | 工坊、炉具、炼金炉、药房、模具 | 燃料、原料、学徒、维修、标准化部件 |
| 防护 | 哨塔、城墙、训练场、武器、护甲 | 建材、武器维护、军饷、情报、后勤 |
| 流通 | 道路、桥、渡口、驿站、载具、账本 | 路桥维护、驮兽饲养、信用担保、护送 |
| 统合 | 会堂、粮仓、档案、祭坛、度量衡 | 书记、仪式材料、税/贡、保管与审计 |

因此，岗位系统必然和市场系统相连：

1. 岗位承接有效需求，产生产出。
2. 岗位为了扩大产出，需求增幅器。
3. 增幅器需要其他岗位提供材料、建造、维护、运输和保护。
4. 这些需求进入市场/互惠/再分配网络，形成新的岗位机会。

这一层暂时不展开成完整市场模型，只保留接口：每个岗位可以声明自己依赖的 `capital_need`（设施/工具需求）和 `maintenance_need`（维护需求）。这些需求交给晶石经济与商路系统处理，由互惠、再分配或市场交换来满足。

### 0.8 地位/阶级近似规则

对每个槽计算“地位潜力”：

> **地位潜力 = 岗位机会 × 垄断性 M × 替代困难度 × 产出可见度 × 增幅器控制度**

地位最高的槽会产出该聚落的上层人物或统治集团：

- 供给槽最高：粮仓主、矿主、水源守护者。
- 转化槽最高：工匠大师、炼金师团、庇护炉维护者。
- 防护槽最高：军阀、猎兽武士团、守备队长。
- 流通槽最高：商队联盟、驿路掮客、渡口主人。
- 统合槽最高：首领、祭司、书记官、议事会。

如果某个高地位岗位能把资源、武力、知识、客户关系、信仰，或关键建筑/设施/工具传给下一代，就会从“高声望职业”凝固成阶层。若垄断性低、替代者多，或用户无法稳定感知其产出，它只会产生短期声望，不会形成稳固阶级。

### 0.9 三个输出

这个最小模型每次只需要输出三件事：

1. **职业结构**：五个槽各占多少权重，哪些是全职，哪些只是兼职/季节性。
2. **主导阶层**：当前谁最有地位，原因是控制了哪个瓶颈。
3. **故事钩子**：哪个高需求岗位没有被满足，哪个关键增幅器短缺/损坏，或哪个垄断岗位正在压迫别人。

例子：

| 聚落条件 | 近似输出 |
|----------|----------|
| 富矿 + 高野兽风险 + 低交通 | 供给/防护/转化优先；矿工、守卫、炼金维护者重要；矿主或守备队长上位 |
| 渡口 + 商路稳定 + Beta 货币流通 | 流通/统合优先；商人、信使、账房、护卫重要；商队联盟或渡口主人上位 |
| 粮食丰余 + 低风险 + 高文化 | 转化/统合扩张；工匠、医者、书记、祭仪职业出现；议事会或祭司获得地位 |
| Alpha 灾害频发 + 庇护设施稀缺 | 防护/转化最高；炼金师、封印者、清理队上位；普通人对专家依赖加深 |

这套模型的关键优点是：它不会问“这个时代应不应该有某职业”，而是问“这个世界里谁产生了有效需求、谁有能力承接、产出是否被认可、岗位背后是否存在可垄断瓶颈，以及岗位为了提高产出会继续需求哪些建筑、设施和工具”。因此可以直接适配架空世界观。

## 1. 调研目标

有了聚落，就意味着人不再只是分散地觅食、迁徙和战斗。稳定居住、资源集中、人口密度提高、商路出现以后，社会会开始回答一组更复杂的问题：

- 哪些人负责食物、水源、矿脉、建筑、运输、交易、守卫、知识、仪式和治理？
- 哪些职能只是季节性副业，哪些会变成全职职业？
- 为什么某些职业会获得更高地位，甚至形成阶级？
- 如果世界观不是现实历史，而是晶石、炼金武装、变异兽、复制人和灾害驱动的架空世界，能否仍用更底层的变量推导出分工结构？

本调研的目标是把“社会分工”从具体时代背景中剥离出来，抽象成一套由环境、生产力、武器、交通、经济系统、知识复杂度与权力基础共同驱动的模型。

## 2. 历史演变中的核心线索

### 2.1 低剩余社会：泛用成员与临时分工

在流动性高、剩余低、存储困难的小群体中，分工往往是临时、兼业和关系化的：谁会打猎、谁熟悉草药、谁能调停争端，并不一定构成稳定职业。亲缘和声望比正式职位更重要。

Service 的 band / tribe / chiefdom / state 类型学虽过于线性，但仍提醒我们：政治组织、领导方式和分工深度通常与生计方式、人口规模、剩余和整合方式相关 [1]。Fried 对平等、等级、分层和国家的区分则强调：分工不等于阶级；只有当关键资源和生活机会被制度性不平等地分配时，才进入稳定分层 [2]。

### 2.2 农业与剩余：可养活全职非生产者

Childe 的“城市革命”理论把早期城市与农业剩余、全职专家、统治阶层、书写、长距离贸易和国家组织联系起来 [3]。其中对游戏最有用的不是“城市必然出现”，而是一个更一般的机制：

> 稳定剩余 + 可集中存储 + 可征收/再分配 = 社会可以供养不直接生产食物的专业角色。

这解释了为什么工匠、祭司、士兵、官吏、商人、抄写员等角色通常不会在低剩余环境中大规模出现。它们需要别人持续供养。

### 2.3 人口压力与集约化：不是只有资源多才会复杂化

Boserup 反转了简单的马尔萨斯直觉：人口压力可能推动农业集约化、技术改进和更高劳动投入，而不只是导致崩溃 [4]。这对 Echo 很重要，因为聚落承载压力不一定只产生迁徙，也可能产生：

- 更密集的耕作、采矿和水利维护。
- 更细的劳动组织和调度。
- 更高的管理需求。
- 更强的资源竞争和地位分化。

不过 Boserup 路径也有边界：当环境、技术或政治组织无法继续提高承载力时，压力会转化为饥荒、迁徙、掠夺或裂变。

### 2.4 市场范围与专门化

Smith 将分工视为生产力增长的重要来源，并强调分工受市场范围限制 [5]。在更一般的模型里，“市场范围”不只是现代市场规模，也可以理解为任何稳定需求网络：

- 一个村落只需要兼职铁匠。
- 多个村落共享一条商路后，可以养活全职铁匠、运输者、护卫和中间商。
- 如果交通阻力低、通用货币存在、信用可传播，专门职业会更容易稳定。

这与 Echo 的商路系统直接相连：Beta 晶石降低陌生交易摩擦，商路扩大有效需求范围，从而提高专业化深度。

### 2.5 有机团结：分工越深，依赖越强

Durkheim 区分机械团结与有机团结：低分化社会靠共同信念和相似生活整合，高分化社会靠互补职能和相互依赖整合 [6]。这给 Echo 一个重要方向：

- 早期聚落更依赖同族、共同传说、共同灾难记忆。
- 后期聚落则可能依赖矿工、炼金师、护卫、商队、粮农、祭司、首领之间的互相需要。
- 分工越深，系统越有生产力，也越脆弱：某一关键职业或供应链断裂，会造成连锁危机。

### 2.6 生态-技术共同决定社会结构

Lenski 的生态演化理论将自然环境、人口、技术和能量利用放在社会结构演化的核心位置 [7]。这一点适合架空世界：不必问“现实中中世纪有没有这个职业”，而应问：

- 这个世界能捕获什么能量？
- 哪些资源可被存储、运输、垄断？
- 哪些技术降低了劳动成本或提高了杀伤力？
- 哪些环境风险要求专门防护和知识？

在 Echo 中，晶石、炼金武装、庇护设施和变异兽生态就会像农业、冶金、航运或火药一样，重塑分工。

### 2.7 地位、阶级与权力基础

Weber 的 class / status / party 三分法适合避免把所有不平等都简化成“财富阶级” [8]：

- **阶级 class**：和市场机会、资源占有、生产资料接近程度有关。
- **身份/地位 status**：和声望、生活方式、血统、宗教纯洁性、职业荣誉有关。
- **党派/组织 party**：和组织化动员、政治控制、武装集团、行政职位有关。

Earle 对酋邦权力的研究进一步强调，首领并不只是“最会调停的人”，而是能把经济、武力和意识形态权力组合起来的人 [9]。因此，社会分工一旦产生关键瓶颈，就会反过来生产权力：

- 控制粮仓/晶石库存的人获得再分配权。
- 控制武器和训练的人获得强制权。
- 控制知识、仪式和预言的人获得专家权与合法性。
- 控制商路、交通和信用的人获得中介权。

## 3. 可泛化抽象：条件如何生成分工

### 3.1 输入变量

一个脱离时代背景的社会分工模型，可以从以下基础条件出发：

| 条件域 | 关键变量 | 对分工的影响 |
|--------|----------|--------------|
| 环境 | 资源类型、季节性、灾害、地形阻力、可耕/可采区域 | 决定基础生计、迁徙压力、防护需求与运输成本 |
| 生产力 | 工具、能源、炼金/工艺、单位劳动产出、存储能力 | 决定是否有剩余供养全职专家 |
| 人口 | 总量、密度、增长率、关系网络、聚落占格 | 决定需求规模、协调成本和市场范围 |
| 武器与风险 | 武器杀伤力、防护技术、敌对生物、战争频率 | 决定战士、护卫、猎人、城防和权力垄断 |
| 经济系统 | 互惠、再分配、市场、货币、信用、商路 | 决定职业能否靠陌生人需求维持 |
| 知识复杂度 | 学习成本、传承方式、记录技术、禁忌/秘传 | 决定专家、学徒制、祭司/工程师地位 |
| 制度与信念 | 合法性、传统、宗教、身份规范、职业荣誉 | 决定某些分工是否被尊崇、污名化或世袭 |
| 交通通信 | 路径成本、信息延迟、标准化度 | 决定分工是本地化、区域化还是跨聚落化 |

### 3.2 分工压力

可把“某职能是否会专业化”理解为一个压力结果：

> 专业化压力 = 稳定需求 × 剩余供养能力 × 技能/工具门槛 × 交易范围 × 风险收益  
> − 自给自足效率 − 季节闲置成本 − 信任/协调成本

含义：

- 如果某任务需求稳定、学习成本高、工具昂贵，并且很多人需要它，职业化概率上升。
- 如果任务只在灾害季发生，可能形成季节性角色，而非全职职业。
- 如果交易范围太小，专门化会被市场不足限制。
- 如果信任低、交通难，分工会退回家族/本地互惠。

### 3.3 职能域而非固定职业表

更泛化的做法不是预写“农民、铁匠、士兵、商人”，而是先定义职能域，再由世界条件实例化为职业：

| 职能域 | 解决的问题 | 可能实例 |
|--------|------------|----------|
| 获取 Extraction | 从环境取出生存与生产资源 | 农人、猎人、采矿者、拾荒者、晶石采集队 |
| 转化 Transformation | 把资源变成工具、建筑、武装、药品 | 工匠、炼金师、厨师、建筑师、符文刻印者 |
| 流通 Circulation | 移动物资、信息和人 | 商人、驮队、船夫、信使、掮客 |
| 防护与强制 Protection | 降低暴力、灾害和掠夺风险 | 守卫、猎兽人、雇佣兵、城防维护者 |
| 照料与再生产 Care | 维持人口、健康和日常恢复 | 医者、育儿者、厨役、草药师、庇护所维护者 |
| 知识与解释 Knowledge | 保存经验、预测风险、训练技能 | 长老、祭司、书记、天象师、晶石学者 |
| 协调与裁决 Coordination | 分配资源、安排劳动、解决争端 | 首领、议事会、粮仓管理员、工头、税吏 |
| 意义与合法性 Meaning | 解释牺牲、身份、禁忌和共同目标 | 祭司、传说讲述者、先知、纪念仪式主持者 |

同一职业可以跨多个职能域。例如 Echo 的“炼金师”可能同时属于转化、知识、防护和地位系统；“商队首领”同时属于流通、协调、信用和武装防护。

### 3.4 职业的生命周期

职业不应一开始就完整存在，而应经历几种状态：

1. **人人兼做**：任务简单、需求低、没有专门工具。
2. **临时专长**：某些人更擅长，但仍不是职业。
3. **季节性/事件性角色**：灾害季、贸易季、战争季才集中出现。
4. **全职职业**：有稳定剩余和需求供养。
5. **行会/世袭/制度化身份**：技能传承、工具垄断、声望和规范固化。
6. **阶层化/垄断化**：职业控制关键瓶颈，形成排他权、身份壁垒或统治权。

### 3.5 地位与阶级的生成机制

地位不应只由“收入”决定，而应由一个角色控制的瓶颈决定：

| 瓶颈 | 产生的地位/权力 |
|------|----------------|
| 稀缺资源 | 粮仓主、矿主、晶石保管者获得再分配权 |
| 暴力工具 | 武士、守卫、军阀获得强制权 |
| 高学习成本知识 | 炼金师、祭司、医者、书记获得专家权 |
| 交通与信用 | 商人、驮队首领、掮客获得网络中介权 |
| 意义解释 | 祭司、先知、传说讲述者获得合法性生产权 |
| 行政记录 | 税吏、书记、账房获得抽取与记忆权 |

阶级或等级会在以下条件下稳定：

- 瓶颈可被排他性控制。
- 控制者能把资源、武力、知识或信仰转化为继承规则。
- 下层缺乏替代路径或迁徙出口。
- 社会信念系统承认这种不平等“合理”。
- 反抗成本高于忍受成本。

因此，Echo 的阶级不必预设为“贵族/平民/奴隶”。可以从瓶颈自然长出：矿脉贵族、庇护炉祭司、商路盟主、猎兽武士团、晶石书记、污染区拾荒贱民等。

## 4. 面向 Echo V3 的抽象收敛

### 4.1 文化程度不应只是科技等级

在聚落系统中，“文化程度越高，支持更多格子组成聚落，单格承载越强”。对社会分工而言，文化程度可拆成四个更基础的能力：

| 文化能力 | 作用 |
|----------|------|
| 技能传承 | 能否稳定培养复杂职业，如炼金师、医者、工程师 |
| 记录与计量 | 能否管理库存、债务、税赋、工程和远距交易 |
| 制度信任 | 陌生人能否合作，职业能否跨亲缘网络稳定运行 |
| 标准化 | 工具、货币、度量、道路、庇护设施能否兼容 |

这些能力越强，聚落能承载的职业种类越多，单体聚落规模越大，跨聚落分工也越稳定。

### 4.2 晶石世界观会重排职业优先级

Echo 中的分工不应照搬现实中世纪。晶石和灾害会制造自己的专业化路径：

- **Beta 晶石稳定可储藏**：提高货币、库存、会计、雇佣、商队和信用职业的重要性。
- **Alpha 晶石高危高能**：制造专门的灾害处理者、炼金武装工匠、污染区猎人、封印/庇护维护者。
- **变异兽与高风险地形**：提高护卫、斥候、猎兽人、路标维护者、驿站经营者的价值。
- **复制人文明循环**：记忆、传说、遗产解释者会比普通中世纪社会更重要。
- **多格聚落上限**：当单体聚落无法继续膨胀时，分工可能外溢到卫星营地、矿镇、商路节点和联邦网络。

### 4.3 分工深度与社会脆弱性同源

分工带来效率，也带来依赖。系统应注意记录关键依赖链：

- 粮食生产者依赖护卫清路。
- 矿工依赖粮食和庇护。
- 炼金师依赖晶石、工具和学徒。
- 商队依赖信用、道路和武装。
- 首领依赖再分配、合法性和武力。

当某个职业节点失效，故事就自然出现：炼金师被杀导致庇护炉失修，庇护炉失修导致矿镇无法压制 Alpha 污染，矿镇停产导致商路断供，首领强征导致叛逃。

## 5. 候选模型：社会分工生成器

后续若要设计正式系统，可以把社会分工生成分成四步：

1. **环境与资源扫描**：识别水源、食物、矿脉、灾害、通行瓶颈、敌对生态。
2. **基础需求生成**：按人口、聚落格数、文化能力、风险水平生成生存、生产、防护、流通、知识、治理需求。
3. **职能域专业化**：根据专业化压力，把任务从“人人兼做”提升为临时角色、季节角色或全职职业。
4. **地位/阶层结晶**：检查哪些职业控制瓶颈，并通过财富、武力、知识、信仰或制度转化为稳定地位。

这个模型的优点是，它不绑定现实时代。只要输入条件不同，就能生成不同社会：

- 高危险、低剩余世界：猎人、护卫、巫医、首领重要，分工浅。
- 高剩余、低交通世界：本地工匠、粮仓管理者、传统长老重要。
- 高交通、Beta 货币成熟世界：商人、账房、护卫、信用中介重要。
- 高 Alpha 灾害世界：炼金师、封印师、污染清理队、庇护维护者获得高地位。
- 多聚落联邦世界：信使、议事代表、跨聚落仲裁者、标准制定者变重要。

## 7. 后续原型验证建议

- 给定相同人口，不同环境风险和资源集中度是否会生成不同职业结构？
- 给定相同资源，交通阻力降低或 Beta 货币普及后，是否会出现更多全职商贸、护卫和会计角色？
- Alpha 灾害频率提高后，炼金/庇护/清理职业是否会获得更高地位？
- 当某职业控制关键瓶颈时，系统是否会自然产生地位上升、垄断、世袭或反抗？
- 当单体聚落到达最大占格上限后，分工是否会外溢到卫星聚落和联邦网络，而不是无限堆进一个城市？
