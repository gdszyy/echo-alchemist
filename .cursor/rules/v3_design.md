# v3_design 模块规范

## 模块职责

存放 Echo V3 各系统模块的**涌现目标验收标准**。每份文档定义"当这个模型被放入游戏后，世界应当涌现出什么样的社会现象"，以及"看到什么就说明它只是在跑数字、没有产生社会"的不合格信号。

## 写作规范

新增验收标准文档时，必须遵循以下结构：

1. **机制说明**：这个模型/系统的运作逻辑是什么（不涉及代码实现）。
2. **涌现目标验收标准**：分目标列出，每个目标包含"合格标准"和"不合格信号"两部分。
3. **参考文献**：引用支撑该设计的学术或工程来源。

**禁止**在此目录下写任何代码实现方案、数据结构定义或 API 接口规范。
