# Echo V3 个人决策常识与信念系统：机制说明与涌现目标标准

在利用大语言模型（LLM）等 AI API 模拟个体决策时，单靠客观的“当前处境”不足以产生真实、有差异的人性反应。个体还需要基于自身的**“常识（Common Sense）”**和**“信念（Belief）”**来理解处境。

本文档专门针对“个体 AI 决策的常识/信念输入”这一子系统，基于文化演化双重继承理论、社会认识论以及现代谣言/偏见理论，给出其在游戏中的机制说明与涌现目标标准。

---

## 一、 机制说明：常识是什么，如何流转？

常识并不是写死在全局配置里的真理，而是存在于**每个角色自己脑子里**的动态信念集合。一条信念可以是关于自然规律的（“晶石粉末能止血”），可以是关于社会规则的（“不可直视首领”），也可以是关于某个群体的（“山那边的人都是强盗”）。

### 1. 常识的数据结构

每个角色持有一个**个人信念集（Belief Set）**。集合中的每一条常识/信念包含以下核心维度：

- **内容（Content）**：常识的具体文本描述。
- **可信度（Confidence）**：角色对这条常识的笃定程度。
- **优先级（Priority）**：在提取给 AI 决策时，这条常识被调用的优先顺位。
- **来源（Sources）**：从哪里获得的（自己经历、某位亲友、长者口传）。
- **情绪色彩（Emotional Valence）**：附带的恐惧、敬畏、仇恨或亲近感。

在调用 AI API 模拟决策时，系统会从该角色的信念集中提取**与当前情境相关、且优先级最高的若干条常识**，作为 Prompt 的上下文注入。这保证了不同角色面对同一情境时，会因为“常识”不同而做出不同决策。

### 2. 常识的自发产生与传播（文化演化机制）

常识的产生与传播遵循文化演化的“社会学习（Social Learning）”机制 [1]。除了个人亲身经历的试错外，绝大多数常识是通过以下四种“传播偏向（Transmission Bias）”从他人处习得的：

- **成功偏向（Success Bias）**：模仿并相信那些“过得更好、拥有更多晶石”的人的信念。
- **威望偏向（Prestige Bias）**：采信地位高的人（首领、祭司）的话。这是传说和教条得以确立的核心。
- **同质偏向（Homophily Bias）**：倾向于相信与自己相似、亲近的人。这解释了常识为何往往在“小团体”和“城市”内部高度趋同。
- **从众偏向（Conformist Bias）**：一条信念被越多人持有，就越容易被其他人采纳。这是形成广泛共识的基础。

### 3. 沟通中的互相印证与共识形成

共识的形成并非简单的数据同步，而是社会认识论（Social Epistemology）中反复印证的过程 [2]。

当角色在沟通中听到对方表达了一条自己已有的常识时，该常识的**可信度和优先级会上升**。为了防止“回音室效应”导致荒谬的谣言无限放大，系统在底层机制上区分了**独立来源**与**重复转述**：从不同的人那里听到同一件事（独立印证），比同一个人反复说一百次，更能提升可信度。

### 4. 传说的特殊性

传说（Legend）是常识的一个特殊子类。根据现代传说与谣言理论 [3]，传说是被群体集体打磨过的信念。在系统中，它表现为一种**“高威望来源注入、跨世代不衰减、且抗证伪”**的特殊常识。

传说往往指向无法被日常经验直接检验的事物（如远古的晶石灾变、沉睡的旧神）。由于无法被个人的日常试错推翻，传说的可信度只增不减，并能跨越“灭绝-重生”的周期，成为新文明对旧世界唯一的认知连接。

### 5. 偏见：作为“错误的常识”

偏见（Prejudice）并不需要一套独立的系统，它就是常识系统在特定条件下的“病态表现”。

偏见是一种**指向特定外群体（Outgroup）、被情绪强化的、抗修正的错误常识**。当一条常识涉及对立群体时，基于“确认偏误（Confirmation Bias）”，角色会本能地只采信印证该偏见的证据，而忽略反例。偏见通常带有强烈的恐惧或仇恨色彩，因此在提取给 AI 时具有极高的优先级，导致角色做出非理性的排斥决策。

## 二、 涌现目标验收标准

当这套常识与信念系统放入游戏后，它必须让世界涌现出以下说得通的社会与认知现象。

### 目标一：基于不同常识的差异化决策

**在社会里扮演的角色**：打破千人一面的 AI 决策，让角色的行为符合其出身、阅历和所处的信息环境。

**合格标准**：
- 面对同一个陌生旅人，不同城市的角色会有截然不同的反应：有的因“常识说外乡人带来瘟疫”而驱逐，有的因“常识说旅人带来财富”而欢迎。
- 这种差异必须能追溯到他们各自的个人信念集，而信念集的形成又能追溯到他们各自所处的城市或小团体。

**不合格信号**：
- 所有角色对同一事件的反应完全一致，仿佛所有人都连着同一个“真理数据库”。
- 角色做出的决策与其背景设定（如长期生活在封闭部落中）的常识严重违和。

### 目标二：共识的自发形成与地域性

**在社会里扮演的角色**：让“文化”和“风俗”在地理上自发形成斑块，而不是被全局设定。

**合格标准**：
- 在没有外部强制规定的情况下，一个封闭的小团体或城市内部，会自发涌现出高度一致的常识（如对某种食物的禁忌）。
- 常识的分布呈现出地域性：相邻的聚落常识相似度高，远隔重洋的聚落常识差异大。
- 能够观察到一条新常识（如“某种新晶石有毒”）顺着商路和人际关系网传播，并在沟通中互相印证，最终成为一片区域的共识。

**不合格信号**：
- 一条新常识瞬间全图同步，没有传播的延迟和路径。
- 无论地理距离多远，所有团体的常识库始终保持高度一致。

### 目标三：传说的跨代传承与失真

**在社会里扮演的角色**：承接“灭绝-重生”的核心母题，让旧世界的真实历史以半真半假的形式流传到新世界。

**合格标准**：
- 在发生大规模灭绝和文明重建后，旧世界的一场真实战争，会在新文明中以“神话”或“传说”的形式存在于角色的常识库中。
- 传说在口耳相传的过程中会发生可追溯的失真（如人物名字变化、细节夸张），但其核心情绪和对某些地点的敬畏得以保留。
- 角色基于这些传说做出决策（如避开某片旧日战场的废墟）。

**不合格信号**：
- 灭绝后，旧世界的一切信息彻底清零，新文明对过去一无所知。
- 传说与客观历史完全一致，没有任何传播中的失真或神话化。

### 目标四：偏见的形成与消解

**在社会里扮演的角色**：为群体间的冲突提供认知基础，并为故事提供“和解”或“加深仇恨”的叙事弧线。

**合格标准**：
- 两个长期缺乏接触或有过一次冲突的团体之间，会自发产生针对对方的偏见（如“山里人都是野蛮的”）。
- 偏见会导致个体在面对该群体成员时，无视客观情况，直接做出敌对决策。
- 偏见具备“抗修正性”，但在特定的“群际接触（如长期的和平贸易或共同抗敌）”后，偏见的可信度会逐渐下降，最终被新的常识覆盖。

**不合格信号**：
- 角色对其他群体的认知永远绝对客观，不存在任何误解或刻板印象。
- 偏见一旦形成就永久不可改变，或者仅凭一次简单的解释就瞬间烟消云散。
