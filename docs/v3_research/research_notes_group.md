# 团体决策与权力调研笔记

> 目标：回答用户两类团体逻辑——① 权力驱动（有人说了算，需模拟权力来源/合法性/转移）；② 目标/理念驱动（无领袖，靠共同目的临时聚合）；以及大团体凝聚物缺失导致的 KOL 裂变（游戏中需量化）。

## 1. 权力的来源（French & Raven 五/七种权力基础）

个体凭什么能影响/支配他人，可拆成可量化的几种"权力基础"，每种对应不同的来源与脆弱性：

| 权力基础 | 来源 | 在游戏里对应 | 脆弱性（失去什么就失去权力） |
|----------|------|--------------|------------------------------|
| 强制权 Coercive | 惩罚/暴力威慑的能力 | 武力型首领（动物世界"谁能打谁是老大"） | 武力衰退、被更强者击败 → 立刻丧权 |
| 奖赏权 Reward | 分配资源/晶石的能力 | 财富型/分赃型首领、商队头目 | 资源枯竭、无法再分配 → 丧权 |
| 合法权 Legitimate | 头衔、地位、社会规范 | 世袭/制度任命的统治者 | 规范崩塌、制度被推翻 → 丧权 |
| 参照权 Referent | 个人魅力、追随者认同 | 卡里斯马领袖、宗教先知 | 魅力消退、信仰动摇 → 丧权 |
| 专家权 Expert | 专门知识/技能 | 祭司、贤者、工匠大师 | 知识被证伪或被取代 → 丧权 |
| （信息权/关系权） | 掌握信息/连接权力者 | 谋士、掮客 | 信息失效、靠山倒台 |

**关键设计点**：权力 = 几种基础的加权组合；每种基础都有独立的"存量"和"消耗/补充"。武力型首领一旦战败，强制权归零 → 权力转移。这天然实现了用户说的"失去武力就失去权力"。

## 2. 权力的合法性（韦伯三种合法统治）

权力要稳定，光有"力"不够，还要被被统治者**接受为合法（legitimacy）**。韦伯三种纯粹类型：

- **卡里斯马型（Charismatic）**：合法性来自领袖个人的非凡魅力/英雄气/神授。最不稳定——追随者必须持续地"再确认"他的魅力；领袖一死或失去光环，立刻瓦解。→ 对应宗教先知、起义领袖、临时英雄。
- **传统型（Traditional）**：合法性来自"亘古如此"的传统/习俗（族长、世袭君主、封建）。靠惯性维系，阻碍理性化。→ 对应部落长老制、世袭王权。
- **法理型（Rational-legal）**：合法性来自一套规则/制度，服从的是"职位"而非"个人"，离任即失权。→ 对应成熟官僚制、议事会。

**演化序列**：卡里斯马 →（领袖死后"常规化 routinization"）→ 传统/法理。这给游戏一个天然的政权演化弧线：一个魅力领袖建立部落 → 死后要么散伙、要么传给子嗣变成传统型、要么固化成制度型。

**合法性 vs 权力**："权力（Macht）"是强迫服从的能力，"权威（Herrschaft/authority）"是被接受为合法的权力。游戏里两者要分开建模：纯靠武力压制（高权力、低合法性）的统治成本高、易反叛；高合法性的统治稳定且廉价。

## 3. 两种团体凝聚逻辑

### A. 权力驱动型（科层/首领型）
有明确权力中心，团体决策 = 首领（受其权力基础与合法性约束）的决策。武力型、宗教型、传统型各有不同的决策风格与脆弱性（见上）。

### B. 目标/理念驱动型（无领袖临时聚合）
没有单一权力中心，成员因**共同目的或共同理念**临时聚在一起，目标达成（或破裂）即解散。常见于小队、远征队、临时联军。这类团体的"凝聚力"来自目标一致度，而非服从。可借合作博弈/联盟形成模型量化：只要"留在团体的收益 > 单干收益"，团体就维持。

## 4. 大团体的凝聚物与裂变（KOL 裂变的量化）

**核心张力**：团体越大，成员间目标/理念越难自然一致 → 需要一种"凝聚物（类宗教的共同信仰/认同/传说）"来抵抗离心力；凝聚物不足，就沿断层线裂变。

裂变机制（组织裂变 / group fission 理论要点）：

- **断层线（Fault line）**：团体内部基于属性（血缘、地域、理念、利益）形成的潜在分界。断层线越清晰、子群边界越重合，越易裂变。
- **触发条件 = 内部冲突 + 子群边界**：仅有冲突或仅有边界都不够，二者叠加才推动裂变。
- **裂变诱因（来自族群政治组织裂变研究）**：领导权竞争、理念分歧、资源分配不均、外部压力变化。
- **游戏量化简化（已按新版验收口径收口）**：现实中是"多个 KOL 各怀心思、循序渐进"地分裂；游戏里可简化为：
  - 给团体一个**凝聚度（cohesion）** 指标 = 共同理念/信仰强度 + 共同利益 + 领袖合法性 − 内部断层张力。
  - 当凝聚度跌破阈值，先沿断层线划出可能分裂的一侧，再从这一侧筛选 KOL 候选。候选分来自关系中心性、潜在权力基础、共同信念代表性、近期震荡事件卷入度和可行动资源。
  - 追随者不是被切半分配，而是沿关系网和服从分量逐个转移：越亲近新 KOL、越处于断层线同侧、越不再服从原领袖的人，越可能出走。
  - 凝聚度受规模负反馈：团体越大，维持同等凝聚度所需的"凝聚物（宗教/认同/传说，复用常识系统中的传说）"越强。

## 5. 与既有系统的衔接
- **常识/信念系统**：宗教/理念凝聚物 = 团体成员共享的高优先级"信念/传说"。凝聚度可由成员信念集的重合度度量。
- **关系网络**：断层线 = 关系网中的稀疏割面；裂变 = 沿割面切开。
- **核心人物调度**：浮现出的新 KOL 自动升格为值得细写的核心人物。
