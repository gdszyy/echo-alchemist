# Echo V3 城市与经济系统：机制说明与涌现目标标准

在 Echo V3 的世界模拟中，单纯的人际关系不足以支撑文明的骨架。城市作为基于地理位置的实体，以及连接它们的经济网络，是整个中世纪背景下社会演化的物质基础。晶石（高能的 Alpha 和惰性的 Beta）不仅是能源，更是驱动所有社会活动（定居、贸易、战争）的核心资源。

本文档针对“城市/聚落、晶石经济与商路”这一子系统，基于中心地理论、引力模型与空间价格均衡等经典经济地理学理论，给出其在游戏中的机制说明与涌现目标标准。同时，明确该层级如何向下与“战斗层（肉鸽关卡）”衔接，向上为“地缘政治层”提供演化基础。

---

## 一、 机制说明：晶石经济如何驱动城市与商路

城市与经济系统的运作是一个自下而上、局部建构的序贯博弈过程（基于 ACE 经济体 ABM 理念）[1]。

### 1. 城市的建立与分级（中心地理论的动态演化）

城市不是凭空设定的，而是基于地理与资源禀赋演化而来的。
- **选址与资源圈**：团体在建立聚落时，会优先选择靠近水源、易守难攻（地形阻力大）且周边有 Beta 晶石矿脉的地点。根据冯·杜能（Von Thünen）的孤立国模型 [2]，城市会围绕自身形成一个基于运输成本的“资源采集圈”。
- **层级分化**：系统基于动态的中心地理论（Central Place Theory）[3]，通过门槛需求（Threshold）与商品范围（Range）决定城市的层级。提供高级服务（如炼金武装打造、高级晶石交易）的城市需要更大的门槛人口，因此数量少且间距远；提供基础生存物资的聚落则数量众多。
- **生物部落屏蔽**：非人类生物部落不参与此经济网络，它们仅在城市的资源圈外围游荡，作为环境阻碍（地形通行代价的一部分）存在。

### 2. 晶石价格与空间均衡

晶石是世界的硬通货。每个城市都有自己的“晶石库存”与“物价指数”。
- **供需决定价格**：城市的繁荣度消耗晶石，采矿队产出晶石。当 Alpha 晶石狂潮（灾害）爆发或矿脉枯竭时，供需失衡导致物价剧烈波动。
- **空间价格均衡**：如果城市 A 与城市 B 的晶石价差大于两地之间的运输成本（包含地形阻力与安全风险），套利空间便出现，商队（目标驱动型团体）就有动机在两地间贩运物资 [4]。

### 3. 商路的自动连接与断裂传导

商路是不需要预先硬编码的，它是商队寻路行为在宏观上的涌现轨迹。
- **引力模型连接**：两地间的贸易流量服从引力模型（Gravity Model of Trade）[5]，即与两地的人口/经济规模成正比，与地形阻力成反比。流量越大的路线，越容易固化为稳定的商路。
- **牛鞭效应与断裂传导**：商路不仅是物流通道，更是经济震荡的传导器。当一条关键商路因战乱或晶石灾害断裂时，供应链的断层会引发牛鞭效应（Bullwhip Effect），导致远方依赖该商路的城市出现物资短缺、物价暴涨，进而引发社会动荡。

### 4. 经济向个体的降级结算（战斗内核的衔接）

宏观经济的震荡必须能够转化为微观的个体动机与玩家可参与的肉鸽关卡。
- 当商队因为引力模型自动寻路时，如果其途经的节点恰好遭遇“火属性 Alpha 晶石灾害”或游荡的“火属性变异兽部落”，宏观的“运输成本/风险”在这一刻**降级实例化**。
- 系统会反向推演出一个“采矿队/商队遭遇火属性野兽袭击”的局部冲突。玩家作为“回声炼金师”介入，此时敌人的属性（火属性）、词缀以及掉落的“炼金武装（符文）”完全由该地块的气候和晶石状态决定。
- 战斗的结果（商队存活或覆灭）将直接写回经济网络，影响该次贸易的成败及后续物价。

## 二、 涌现目标验收标准

当这套城市与经济系统放入游戏后，它必须让世界涌现出以下说得通的经济地理现象，并能为叙事提供动机。

### 目标一：基于地理与资源的城市兴衰

**在社会里扮演的角色**：让城市的分布和规模符合经济常识，而非均匀撒点。

**合格标准**：
- 城市的选址和规模能够被解释：大城市总是出现在商路枢纽或富矿区，小聚落散布在周边提供基础资源。
- 一座城市的兴衰有迹可循：某地因发现新晶石矿而迅速繁荣，后因矿脉枯竭或商路改道而逐渐衰败为废墟。这些宏观大事件（如“晶石矿坍塌”）能作为硬骨架，被反向推演系统挂接。

**不合格信号**：
- 荒芜的沙漠中心凭空出现一座没有任何资源支撑的繁华大都会。
- 城市的繁荣度只是随机涨落，与周边的矿产产出或贸易网络毫无关联。

### 目标二：价格波动驱动的社会动机

**在社会里扮演的角色**：将抽象的经济数据转化为具体的社会行动（迁徙、结盟、背叛）。

**合格标准**：
- 某地晶石价格暴涨时，能够观察到周边城市的商队（逐利动机）大量涌入，甚至引发附近势力的眼红和掠夺。
- 经济崩溃（如物价极高导致饥荒）会成为底层民众（个体层）形成临时团体并向外迁徙的直接推力。

**不合格信号**：
- 无论晶石多稀缺，价格永远是恒定的；或者价格波动从不影响任何商队的路线或人口的流动。

### 目标三：商路的自发形成与连锁震荡

**在社会里扮演的角色**：把孤立的城市连成一张牵一发而动全身的经济网。

**合格标准**：
- 地图上能够自发涌现出连接主要经济节点的贸易路线，且这些路线合理避开了高通行代价（如高耸山脉或高危生物区）的地形。
- 当某条主干商路被截断（如遭遇高阶变异兽盘踞）时，系统能推演出一系列连锁反应：沿线城市物价飞涨、商队破产、乃至引发暴乱。这一连串事件能被讲述为一个完整的“商路断绝引发的危机”故事。

**不合格信号**：
- 贸易路线是预先写死的，断绝某条路线对世界其他地方毫无影响，两地只是在凭空交换数字。

### 目标四：经济风险向肉鸽关卡的合理降级

**在社会里扮演的角色**：确保宏观模拟能无缝生成玩家可游玩的、带有特定属性的战斗关卡。

**合格标准**：
- 玩家接到的“救援商队”任务，其发生地点必定在当前真实活跃的商路上，且敌人的属性（如冰、雷）与该地块当前的晶石灾害环境完全吻合。
- 玩家完成关卡后，商队得以存活，该商路的物资成功抵达目的地，平息了当地的物价波动（微观战斗切实影响宏观经济）。

**不合格信号**：
- 玩家在火山地带的商路救援任务中，打的却是与环境毫无关系的冰属性敌人。
- 玩家无论输赢，宏观商路的贸易额和目标城市的物价都不受任何影响。
